# Αποκτήστε την εφαρμογή

Κατεβάστε την εφαρμογή για να έχετε πρόσβαση στις προσευχές σας εκτός σύνδεσης
και να λαμβάνετε ενημερώσεις υπενθύμισης για προσευχή και νηστεία. Η εφαρμογή
υποστηρίζει επίσης το Ιουλιανό ημερολόγιο ως επιλογή αντί για το Γρηγοριανό
ημερολόγιο.
